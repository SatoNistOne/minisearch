# minisearch

Распределённый полнотекстовый поиск на Rust с веб-интерфейсом. Документы разложены по 3 шардам (у каждого по 2 реплики), координатор собирает ответы и ранжирует результаты по BM25 с общей для всех шардов статистикой. Готовые поисковые движки не используются, индекс написан с нуля.

Что умеет:
- поиск по русскому и английскому тексту со стеммингом, режимы «любое слово» / «все слова», фразы в кавычках (`"…"`, `«…»`, `“…”`, `„…“`);
- надбавка к оценке, если слова запроса стоят рядом; синонимы из небольшого словаря (батон → хлеб);
- поиск во время набора: «закв» находит «закваска»;
- нечёткий поиск (опечатки) и автодополнение;
- загрузка файлов `.txt`, `.docx` и `.pdf` через сайт, список документов с сортировкой и фильтром по типу;
- просмотр документа с подсветкой найденных слов, редактирование, удаление, скачивание исходного файла;
- хранение на диске (снапшот + журнал записей), данные переживают перезапуск;
- реплики: при падении одной копии шарда поиск продолжает работать.

## Запуск

Нужен [Docker](https://docs.docker.com/get-docker/) с `docker compose`: на Linux пользователь должен быть в группе `docker`, на Windows и macOS нужен запущенный Docker Desktop.

```
git clone https://github.com/SatoNistOne/minisearch.git
cd minisearch
```

| Система | Команда | Остановка |
|---|---|---|
| Linux, macOS | `./serve.sh` | Ctrl+C или `./serve.sh stop` |
| Linux с fish | `./serve.fish` | Ctrl+C или `./serve.fish stop` |
| Windows | `powershell -ExecutionPolicy Bypass -File serve.ps1` | Ctrl+C или та же команда с `stop` в конце |

Первый запуск собирает образ, это занимает несколько минут. Затем скрипт выводит адреса сайта: для этого компьютера и для других устройств в той же сети.

- **Linux с файрволом `ufw`:** скрипт спросит пароль `sudo`, откроет порт 7000 на время работы и закроет его при остановке, проверив по `ufw status`.
- **Windows:** при первом запуске система может спросить, разрешить ли Docker Desktop доступ к сети. Разрешите для частных сетей, иначе другие устройства сайт не увидят.

Сразу после установки база пустая. Загрузить 15 демонстрационных текстов из `data/sample`, пока сайт запущен:

```
docker compose --profile load run --rm loader
```

Вручную, без скриптов: `docker compose up -d --build`, сайт на http://127.0.0.1:7000, остановка `docker compose stop`.

## API координатора (порт 7000)

| Запрос | Что делает |
|---|---|
| `GET /search?q=&from=&size=&operator=or\|and&fuzzy=true&prefix=true&synonyms=false&proximity=false` | поиск; `prefix` дополняет последнее слово, синонимы и бонус за близость включены по умолчанию |
| `GET /suggest?prefix=` | автодополнение |
| `POST /upload` (multipart, поле `files`) | загрузка `.txt`/`.docx`/`.pdf` |
| `GET /docs?after=&size=&sort=id\|title\|created\|size&desc=true&format=pdf` | список документов |
| `GET /docs/{id}?hl=` | один документ; `hl` — термы из ответа поиска (`terms`) для подсветки |
| `GET /docs/{id}/file` | исходный файл (для документов без файла — текст `.txt`) |
| `POST /docs`, `PUT /docs/{id}`, `DELETE /docs/{id}` | добавление (JSON), замена, удаление |
| `GET /stats`, `GET /health`, `GET /analyze?text=` | состояние шардов, проверка, токены анализатора |

## Устройство

`src/`: `analyzer` (токены, стоп-слова, стемминг), `index` (инвертированный индекс с позициями), `scoring` (BM25), `query` (фразы, сниппеты), `fuzzy`, `storage` (снапшот + WAL), `extract` (txt/docx/pdf), `synonyms`, `shard`, `coordinator`. Страница сайта — `web/index.html`.

Поиск идёт в два раунда: координатор сначала собирает статистику со всех шардов, затем запрашивает у них top-k с общими значениями IDF, поэтому оценки совпадают с поиском по одному общему индексу.

## Ограничения

- Нет пользователей и прав доступа: любой, кто открыл сайт, может загружать и удалять документы.
- Реплики не согласуются между собой: реплика, недоступная во время записи, остаётся без этих изменений.
- Поддерживаются `.txt` (UTF-8), `.docx` и `.pdf` с текстовым слоем (сканы не распознаются); файл до 10 МБ.
- Полные тексты хранятся в памяти шардов, проект рассчитан на тысячи документов, а не на миллионы.
